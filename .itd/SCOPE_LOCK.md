- The shared hooks' decisions: pii-egress-guard.sh, model-policy.sh and itd_external_write_gate.py keep their

  for the dispatcher) is denied; the external-write gate CLI `approve` stays forbidden.

## Known limitation (accepted with variant A)
- The approval store is protected only by the OS user's file ownership (POSIX: owner + no group/other write;
  Windows: owner SID = the user's TokenUser SID, the inherited profile DACL is not inspected) and by a guardrail that denies tool calls naming
  the channel. A process running as the user that bypasses the hook transport can still write a record. This is
  weaker than Claude's native prompt; the hash binds exactly one call (hook, tool, full input, cwd).
