# SCOPE_LOCK — GENG-C-EXP (открыт 2026-08-28)

## Предмет
N8: единственный уцелевший пункт программы GENG — ОДИН bounded-эксперимент,
без GENG-A и без GENG-B (оба закрыты решением владельца 2026-08-22 на GATE G0,
NO-GO подтверждён перемером N6). Проверяется ровно один неизмеренный вопрос:

> находят ли N параллельных независимых ревьюеров на ОДНОМ кандидате то, что
> сегодня приходит в последовательных раундах 2..N?

Протокол пре-регистрирован ДО чисел:
`.itd-memory/measurements/GENG-C-EXP-protocol.md`.

Измеренное предусловие (эта сессия): ни одна пара сохранившихся заходов не
делит кандидата — в серии N7 (r2-r7) дайджесты промптов попарно различны,
размер растёт монотонно 527 035 -> 583 224 байт. Ретроспективно «в лоб»
вопрос не отвечается, поэтому юнит разделён на фазу 0 (декомпозиция истории,
без затрат на модель) и фазу 1 (живой эксперимент, 12 пар) — фаза 1 стартует
ТОЛЬКО по отдельному решению владельца, стоимость названа в протоколе.

## Разрешённые области
- `.itd-memory/measurements/GENG-C-EXP-protocol.md` — пре-регистрация; после
  появления чисел правится только новой версией с явной причиной.
- `.itd-memory/measurements/GENG-C-EXP-phase0.py` и `-phase0.json` —
  классификатор PRE/NEW/UNDECIDABLE и его результат. Классификация
  МЕХАНИЧЕСКАЯ (наличие якорной строки в байтах промпта предыдущего раунда),
  не суждением; не-слепота классификатора объявлена в протоколе.
- `.itd-memory/measurements/GENG-C-EXP-check.py` — fail-closed чекер замера
  (перепроверяет корпус, классы и агрегаты из строк).
- Леджерная бухгалтерия юнита: `.itd-memory/STATE.json`,
  `.itd/ACCEPTANCE_CONTRACT.json`, `.itd/DECISIONS.md`, `BACKLOG.md`,
  `LAUNCH_PLAN.md` (Block J / раздел GENG).
- Только при явном решении владельца по фазе 1: артефакты живого прогона под
  `benchmarks/geng/` и код флага **default-off**.

## Явно вне скоупа
- GraphSpec / NodeContract / GraphAuthorization (GENG-A) и dual-digest
  proof-cache (GENG-B) — закрыты, этим юнитом не воскрешаются.
- Любое поведение по умолчанию: результат эксперимента может дать только
  opt-in флаг, выключенный по умолчанию.
- Изменение обязательного маршрута ревью (продюсер, чекер, адъюдикация) —
  эксперимент МЕРЯЕТ маршрут, но не правит его в этом юните.
- Подмена популяции молча: если вместо обязательного cross-vendor продюсера
  меряется субагент-чекер, это объявляется в вердикте как другая популяция.

## Правило остановки
Две итерации фазы 1 без выхода на заранее объявленный порог — стоп и решение
владельца; третья не запускается. Для ревью-серий по кандидату юнита действует
общее правило: два BLOCKED подряд — стоп.
