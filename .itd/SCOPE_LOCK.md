## Предмет
PILOT P0-1 из `.itd-memory/ADVISORY-RSI-2026-08-27-v4.md` §5 — единственный
пункт RSI-плана, активируемый сразу. Схема вердикта получает ЗАКРЫТЫЕ enum

запись не теряется, а уходит в карантин со счётчиком.

## Замер ДО правки (первый шаг контракта, выполнен 2026-08-29)
`.itd-memory/review-findings.jsonl`: 104 записи, 130 findings.
- `severity`: 17/130 вне словаря {critical, important, minor} — пустая строка
  x13, `low` x2, `high` x1, `medium` x1.
- `category`: заполнена 16/130 (114 = null), 14 разных свободных строк.
- `source`: поля нет вообще, 130/130 записей без провенанса (§7 требует
  source+lineage).
Механизм 114 пустых категорий назван: собственный retry-текст хука (`REASON`)
никогда не просил `category` — модель отдаёт то, что у неё спросили.

## Разрез (согласован владельцем 2026-08-29, паттерн §5)
1. **PILOT-P01 (этот юнит, setup)** — enum + reject-on-write + карантин +
   счётчик + taxonomy_version + mapping легаси + тесты. Машинный оракул.
2. **Наблюдение** — фоновое накопление новых записей, БЕЗ WIP.
3. **PILOT-P02 (decision, отдельный юнит)** — слепой семантический протокол
   (владелец категоризует 10 случайных новых находок по тексту, метка автора
   скрыта, совпадение >= 8/10). Он и есть гейт для Q2.
Основание разреза: слепой протокол требует >=10 НОВЫХ находок, которых после
правки ещё не существует; держать WIP до их накопления — ровно тот
антипаттерн, который §5 запрещает.
