# Task contract — PILOT-P02-CLOSE (medium)

## Scope
Закрытие PILOT-P02 маршрутом диспозиций STOPRULE-2: код замороженного кандидата
(дерево 64d6b4bc, серия r1-r70 в параллельной сессии; находки r58 и r59 закрыты там же, открытых нет)
перенесён на свежую ветку от main 75bd05c без изменений по существу. Предмет ревью — тот же:

1. Замороженный контракт замера `skills/_shared/BLIND_PROTOCOL.json`
   (`protocol_version: 1`): популяция, размер выборки, порог, видимые поля
   листа, правила скоринга, честная маркировка, fail-путь, ограничения.
2. Машинерия `skills/_shared/itd_blind_protocol.py`: строгая загрузка
   протокола (fail-closed), фильтр популяции, воспроизводимая жеребьёвка,
   печать с tamper-evidence, слепой лист, скоринг с порогом, CLI из трёх
   команд.
3. Оракул `tests/verify_blind_protocol.py` на ЗАПЕЧАТАННЫХ фикстурах, не на
   живом леджере: замер обязан перепроверяться на любой машине.
4. Регистрация сьюта в зеркале `run-all` и обоих файлов в манифесте
   установленного runtime.

## Verification standards
- RED-first: каждая гарантия сначала краснеет на мутации, затем зеленеет.
  Мутации (все летальны): снять требование штампа версии -> красный;
  семплировать неполную популяцию -> красный; убрать сортировку популяции ->
  красный; жеребьёвка с возвратом -> красный; показать `category` в листе ->
  красный; взять плоский словарь вместо `bySource` -> красный; не применять
  порог -> красный; не ловить правку записи после печати -> красный;
  разрешить вторую попытку -> красный; не ловить подмену протокола ->
  красный; засчитать неполный лист -> красный; засчитать внесловарный ответ
  -> красный.
- Честно: правка `verify_runall_drift.py` — проверка, привязанная к живому
  дереву, как и соседние проверки консолидации; изолированной мутацией этот
  класс не ловится. Опора — зелёное зеркало и сохранившиеся проверки доноров,
  кипера и узлового множества.

## Definition of done
Оракул зелёный, все мутации летальны, полное зеркало без новых красных,
файлы объявлены в манифесте, бухгалтерия юнита согласована, независимое
cross-vendor ревью дало чистый PASS ЛИБО серия остановлена стоп-правилом (политика 1.2.0) и
BLOCKED-квитанция закрыта подписанными владельцем диспозициями ADR-007 (adjudication
`ADJUDICATED`) — оба исхода равноправно закрывают DoD; публикация прошла маршрут.

## Explicitly NOT done here
Вердикт протокола: популяция новых находок пуста (0/260 со штампом версии),
раскатки таксономии на хост не было. Вердикт выносит отдельный decision-юнит.
