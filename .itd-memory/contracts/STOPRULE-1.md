# Task contract — STOPRULE-1 (medium)

## Scope
1. R7 `SURFACE_TREADMILL` в политике стоп-правила (1.1.0) и `decide()`:
   окно `windowRounds` вердикт-раундов, все BLOCKED, каждая засчитанная
   находка в строках, добавленных относительно базы серии; прецедент после
   терминалов повтора, перед ROUTE_REPAIR; правило остаётся advisory.
2. Улика поверхности класса `diff-hunks` (проекции `full`/`hunk-headers`
   вывода `git diff -U0`), sha256 в дереве, база серии `surfaceBaseline`,
   пересчёт по живым деревьям.
3. Парсер иерархических отчётов продюсера; `line` у находок (report и
   narrative); `candidateSource.kind=reviewed-tree`.
4. Фикстура PILOT-P02 (73 захода) с архивом 18 проекций и записью находок из
   транскрипта; синтетический позитив R7; контроли без смены терминала.

## Verification standards
- RED-first: политика 1.1.0 краснит старый оракул на прецеденте; код
  возвращает зелёный; каждая новая гарантия — своя проверка и своя мутация.
- Мутации кода правила (12): снятие проверок пустого раунда / BLOCKED /
  недостающей улики / локализации, разбор проекции, sha, база, порядок R7-R1,
  строка находки, дедуп иерархии, префикс reviewed-tree, контекст в -U0 —
  все летальны.
- Мутации политики (12) отвергаются загрузчиком.
- Реплей P02 совпадает с независимым замером (REDESIGN_OR_DISCARD @ r14).
