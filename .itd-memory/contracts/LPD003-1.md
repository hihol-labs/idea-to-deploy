# Task Contract — LPD003-1

## Scope
run-all как машинный оракул: класс BLOCKED для host-owned входа, `--fail-fast`,
`--targeted` по `.itd/IMPACT_GRAPH.json` + `.itd/IMPACT_PATTERNS.json`,
строка MIRROR-COVERAGE. Новый оракул `tests/verify_targeted_regression.py`.
Периметр селектора: ни один публичный вход не называет читаемый им файл
(решение 2026-08-24, `.itd/DECISIONS.md`); целостность карты — только
канонические repo-relative пути в узлах и рёбрах.

## Verification Standards
- `python3 tests/verify_targeted_regression.py` — ноль красных (включая мутации
  карты, заведомо ложное no-impact правило, отказ публичных входов, называющих
  файл, dashed-путь ЧЕРЕЗ `run-all.sh` и запрет сужения профиля при strict).
  **Число проверок здесь намеренно не записано:** оно растёт от раунда к раунду,
  а вписанный руками агрегат протухает от следующего же прогона и порождает
  противоречие между записями. Актуальное число печатает сам оракул последней
  строкой; инвариант контракта — ноль красных, а не конкретное число.
- `python3 tests/verify_verification_profiles.py` — impact-audit зелёный после
  регенерации карты.
- `python3 tests/verify_machine_oracle.py`, `tests/verify_runall_drift.py`,
  `tests/verify_quick_regression.py` — дрифт-контракты run-all сохранены.
- `bash tests/run-all.sh` — DONE fails:none.
- Замер: полный прогон vs targeted на 2-3 реальных юнитах (числа в CHANGELOG).

## Exclusions
Ремонт сьютов вне зеркала; LPD-003-2/3/4; изменение гейтов.
