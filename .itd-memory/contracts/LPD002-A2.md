# Task Contract — LPD002-A2 (сессия долгов LPD-002)

## Scope
Стейл-оценщик completion-гейта (`hooks/completion_lib.py`), самый частый
измеренный долг плана: каждый коммит R5/R6 шёл через `COMPLETION_BYPASS`,
гейт фактически выключен привычным обходом. Три корня, все воспроизведены
RED-first на старом коде:
1. display/write-команды классифицировались как test_run по проектным
   L2-паттернам (heredoc `cat >> HANDOFF.md`, `grep … tests/run-all.sh`) —
   теперь `display_only_command()` отсекает их ДО классификации;
2. идентичность «latest-на-команду» была сырой строкой — зелёный
   `cmd | tail` не вытеснял красный `cmd | grep`; теперь ключ —
   `normalize_command_key()` (quote-aware разрез пайпа, display-хвосты и
   хвостовые редиректы отброшены);
3. красный сигнал жил вечно через границы коммитов — теперь сигнал несёт
   `head`, и красный от чужого HEAD — стейл (без head — консервативный блок).

## Verification Standards
- Оракул: `completion-signal-classes-oracle` =
  `python3 -I tests/verify_completion_signal_classes.py` (15 -> 54 проверок: +hd-раунды PUB3 — heredoc-семантика и here-string; +3 PUB4 — общий класс слов-делимитеров END-1/E-D/EOF.txt).
- Пропорциональный набор по карте R6 (`impact-audit`/select для
  `hooks/completion_lib.py`): 13 сьютов-владельцев — все зелёные
  (два лок-флейка `verify_state_hardening`/`verify_harness_map_fixtures`
  зелёные при прямом повторе — класс A9; `verify_operating_loops_release`
  красный и на немодифицированном дереве — pre-existing исторический пруф
  v1.94, вне run-all, вне скоупа).
- Мутации в обе стороны:
  - недоблокировка: display-кейсы -> None; стейл-красный не блокирует;
  - переблокировка: настоящий run-all/pytest остаётся сигналом; пайп с
    display-хвостом остаётся сигналом; красный ДРУГОЙ команды не
    вытесняется; красный на текущем HEAD и красный без head блокируют.

## Exclusions
- Остальные долги — свои юниты (см. `.itd/SCOPE_LOCK.md`).
- Rate-limit/verdict-транспорт хуков (`completion-gate.sh`,
  `completion-stop.sh`) не меняются — только библиотека классификации.
