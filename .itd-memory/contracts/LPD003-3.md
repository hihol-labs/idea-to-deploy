# Task Contract: LPD003-3 — правило остановки над содержанием находок

## Scope

- Сформулировать правило остановки цикла независимого ревью над СОДЕРЖАНИЕМ
  находок и проверить его реплеем записанных историй S04b, R6 и GPG-001.
- Единица решения — повтор одного механизма через раунды, а не число заходов.
  Потолок раундов запрещён по построению и проверяется оракулом.
- Классы терминалов раунда (вердикт / предусловие / транспорт) различаются
  машинно: смешанный подсчёт заходов невозможен.
- Правило остаётся **advisory**: оно печатает терминал и основание, решение
  принимает владелец.

## Verification Standards

- `python3 -I tests/verify_stop_rule.py` — контракт политики, реплей историй,
  поведенческие гарантии, мутации входа и провенанса.
- `bash tests/run-all.sh --targeted` на дереве кандидата и полное зеркало
  `bash tests/run-all.sh` перед публикацией.
- Каждая гарантия подтверждается обратной мутацией реализации: гарантия,
  которая не умирает от мутации, считается заявленной, а не проверенной.
- Улики цитируемых раундов сверяются по sha256 с байт-копиями в дереве;
  раунды класса `narrative` помечаются в выводе и машинной уликой не считаются.

## Exclusions

- Правило не становится гейтом и не останавливает маршрут автоматически.
- Машинерия LPD-003-1 (`itd_regression_select.py`, `verify_targeted_regression.py`)
  внутри этого юнита не чинится; найденное несоответствие идёт в BACKLOG.
- Юниты S04b, R6 и GPG-001 по измеренным расхождениям не переоткрываются.
- Классификация «находка мимо предмета юнита» намеренно НЕ вводится: из полей
  находки она машинно не выводится, а выводимая руками — это подкраска.
